# Porchlight Releases

This repository holds the downloads for **Porchlight Slideshow** and **Porchlight Player**, made by Never Never Gear for families creating memorial and celebration slideshows. It contains no source code, only release files.

## Download

- **Porchlight Slideshow**, to make slideshows: [Mac](https://github.com/mrichmond/porchlight-releases/releases/latest/download/Porchlight-Slideshow-Mac.dmg) · [Windows](https://github.com/mrichmond/porchlight-releases/releases/latest/download/Porchlight-Slideshow-Windows.exe)
- **Porchlight Player**, to play them (free; Porchlight Slideshow also puts a copy beside every slideshow it publishes): [Mac](https://github.com/mrichmond/porchlight-releases/releases/latest/download/Porchlight-Player-Mac.dmg) · [Windows](https://github.com/mrichmond/porchlight-releases/releases/latest/download/Porchlight-Player-Windows.exe)

Earlier versions are on the [Releases page](../../releases).

The other files in each release (`latest.json` and the `.sig` files) are used by Porchlight Slideshow to update itself. You don't need to download them.

## Updates

Porchlight Slideshow can check this repository for a newer version. Each update is signed, and the app installs it only if the signature matches. The check shares your IP address and the app version with GitHub, and nothing else. Porchlight Player never updates itself.
